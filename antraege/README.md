# Pitches & Förderanträge

Für jedes der 11 Gründerprojekte (`../projekte/`) ein eigenständiges Dokument mit **Pitch** (Teil A)
und **förderfertigem Antrag** (Teil B: Zielprogramm, Arbeitspakete, Zeit-/Meilensteinplan,
Kosten-/Finanzierungsplan, Verwertung, Open-Source-Bezug, Zugang zur öffentlichen Hand, Risiken).

Gründerrolle durchgängig angenommen: **soloselbstständig / Nebenerwerb mit Wachstum**.
EUR-Zahlen sind programmpassende Planansätze — unsichere Werte als „ca."/Spanne markiert.
Vor Einreichung die **aktuelle Programmrunde** (Förderquote, zulässige Posten, Fristen) prüfen.
